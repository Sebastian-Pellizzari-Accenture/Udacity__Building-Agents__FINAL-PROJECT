## What I have learned
During this course/project, you’ve been building practical agent skills around designing AI systems that can do more than just answer from memory.

### **Competences developed**
- **Agent design**
  - Understanding how to structure an agent with instructions, tools, and decision logic.
- **Tool use**
  - Learning how agents call external tools and APIs to complete tasks.
- **Grounding and retrieval**
  - Using external information sources instead of relying only on model memory.
- **Web search integration**
  - Building agents that search the web for current or unstructured information.
- **Evidence-based responses**
  - Making agent outputs more reliable by grounding answers in retrieved results.
- **External API integration**
  - Connecting agents to outside services and using those results in responses.
- **Agentic RAG workflows**
  - Combining retrieval with agent reasoning so the agent can decide which source or tool to use.
- **Domain-focused research agents**
  - Applying these ideas to a specific use case: researching the video game industry with UdaPlay.

## Project summary
In this project, you are working in a hands-on workspace to build or explore an AI research agent for the video game industry. The project focuses on giving the agent access to useful external information sources so it can produce more grounded, relevant, and up-to-date answers.
